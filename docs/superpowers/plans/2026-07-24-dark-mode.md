# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a manual light/dark theme toggle to the whole shoutrrr.com site (marketing + `/docs`), defaulting to light and persisting the user's choice.

**Architecture:** Convert the semantic Tailwind color tokens from hardcoded oklch literals into `var(--token)` references, then define light values under `:root` and soft-charcoal dark values under `html.dark` in `global.css`. Most utilities (`bg-surface`, `text-ink`, `border-line`) flip automatically. Edge cases (dark sections, hardcoded whites, auras, shadows, docs prose, product mockups) are hand-tuned. A no-flash inline `<head>` script and a nav toggle button drive the `html.dark` class + `localStorage`.

**Tech Stack:** Astro 5, Tailwind CSS 3 (`darkMode: 'class'`), Svelte 5 islands, oklch color space, Lucide icons.

## Global Constraints

- Palette selection is **manual only**. Default light. Persist to `localStorage` key `theme` (`'dark'` | `'light'`). Do **not** read OS `prefers-color-scheme`.
- No new dependencies. Lucide icons come from the already-installed `lucide-astro`.
- No test runner exists in this project. Per-task verification = `npm run build` succeeds **and** the stated manual browser checks pass (run `npm run dev`, toggle, hard-reload).
- Keep the lime brand identity: buttons stay lime with deep-lime text in both themes.
- Product mockups (`ComposerMockup.svelte`, `Showcase.svelte`) are intentional **light "app screenshots"** — they stay light in both themes via a `.theme-light` scope, not re-themed.
- Preserve existing behavior: the inline head script currently adds the `.js` class before paint — keep that, extend it.

- [ ] **Step 4: Wire the toggle client-side**

In `src/components/Navigation.astro`, inside the existing `<script>` block (after line 116, the `iconClose` declaration, or anywhere in the module), add:

```ts
  const themeToggle = document.getElementById('theme-toggle');
  const iconSun = document.getElementById('icon-sun');
  const iconMoon = document.getElementById('icon-moon');
  const themeMeta = document.getElementById('theme-color-meta');

  function paintTheme(isDark: boolean) {
    iconSun?.classList.toggle('hidden', isDark);
    iconMoon?.classList.toggle('hidden', !isDark);
    themeToggle?.setAttribute('aria-pressed', String(isDark));
    themeMeta?.setAttribute('content', isDark ? '#343434' : '#ffffff');
  }

  // Sync button/meta to the class the inline head script already applied.
  paintTheme(document.documentElement.classList.contains('dark'));

  themeToggle?.addEventListener('click', () => {
    const isDark = document.documentElement.classList.toggle('dark');
    localStorage.setItem('theme', isDark ? 'dark' : 'light');
    paintTheme(isDark);
  });
```

(`#343434` ≈ `oklch(0.205 0 0)`, the dark background, for mobile browser chrome.)
